## Publish with GitHub Pages
1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. The included workflow deploys the site on pushes to `main`.
5. Open **Actions** and wait for the **Deploy portfolio to GitHub Pages** workflow to finish.
6. The public site address will be `https://nidhi192004.github.io/my-portfolio/`.
